# 🚀 Featured Projects

## 🟣 TeamFlow
### Real-Time Collaborative Project Management SaaS

A full-stack project management platform built for teams to organize projects, manage tasks, collaborate in real time, and leverage AI-powered assistance.

**Highlights**

- 🔐 Authentication & role-based authorization
- 👥 Workspace and member management
- 📋 Project and task management
- ⚡ Real-time collaboration with **Socket.IO**
- 💬 Comments and activity updates
- 🔔 Notification system with **Redis**
- 📎 Cloud file uploads with **Cloudinary**
- 🤖 AI-powered project assistant with **Google Gemini**
- 📧 Transactional emails with **Resend**
- 🗄️ PostgreSQL with **Prisma ORM**
- 🛡️ API validation, security middleware and rate limiting
- 🚀 Production deployment with **Vercel, Render, Neon & Upstash**

🌐 **Live Demo:** [teamflowtech.online](https://www.teamflowtech.online)

📂 **Source Code:** [github.com/anupiit/teamflow](https://github.com/anupiit/teamflow)

## 💼 InsiderJobs
### Full-Stack Job Portal Platform

A full-stack recruitment platform connecting candidates and recruiters through a secure, role-based architecture.

**Highlights**

- 👤 Candidate authentication with **Clerk**
- 🧑‍💼 Recruiter authentication using **JWT**
- 🔐 Role-based access control
- 💼 Job creation and management
- 📝 Candidate job applications
- 📧 Automated application emails using **Resend**
- 📊 Production error monitoring with **Sentry**
- 🛡️ Protected API routes and authorization
- 🗄️ MongoDB database
- ⚛️ React + Tailwind CSS frontend
- ⚙️ Node.js + Express.js backend

🌐 **Live Demo:** [insiderjobs-frontend-clvr.onrender.com](https://insiderjobs-frontend-clvr.onrender.com)
